# SIMATS – C Programming

Welcome to **SIMATS-SLOT-C**, a structured collection of C programming examples and practice programs designed to help students learn programming fundamentals from scratch.

This repository organizes C programming concepts into separate topic-based folders for easy learning, practice, and revision.

## 📚 Topics Covered

| No. | Topic | Description |
|---|---|---|
| 01 | C Introduction | Program structure, syntax, and basic concepts |
| 02 | Input and Output | `printf()` and `scanf()` |
| 03 | Variables and Data Types | Variable declaration and fundamental data types |
| 04 | Constants | Constant values and the `const` keyword |
| 05 | Operators | Arithmetic, relational, logical, assignment, and other operators |
| 06 | Expressions | Expression evaluation and operator precedence |
| 07 | Decision Making | `if`, `if-else`, nested `if`, `else-if`, and `switch` |
| 08 | Looping | `for`, `while`, and `do-while` loops |

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Vimal4hckr/SIMATS-SLOT-C.git
```

### 2. Open the Project in VS Code

```bash
cd SIMATS-SLOT-C
code .
```

### 3. Compile a C Program

Make sure GCC is installed and configured in your system's PATH.

```bash
gcc filename.c -o program
```

Replace `filename.c` with the actual name and path of your C source file.

### 4. Execute the Program

**Windows:**

```cmd
program.exe
```

**Linux/macOS:**

```bash
./program
```

## 🎯 Learning Objectives

- Understand the fundamentals and syntax of C programming.
- Learn variables, data types, constants, and operators.
- Develop logical thinking using conditional statements.
- Solve problems using loops and repetitive structures.
- Practise writing, compiling, debugging, and executing C programs.
- Build a strong foundation for data structures and algorithms.

## 💡 How to Practise

1. Learn each topic in the given order.
2. Read and understand the example programs.
3. Compile and execute the programs on your computer.
4. Modify the code to experiment with different inputs.
5. Solve similar problems independently to strengthen your programming skills.
